# Морзе — тренажер / Morse Trainer

Офлайн-застосунок (PWA) для вивчення та тренування азбуки Морзе. Українська та англійська абетки.
Одна сторінка, без залежностей і без збірки — просто статичний хостинг.

## Що вміє

- **Ключ** — рядок живої розшифровки морзянки в текст, інтерактивне дерево Морзе з підсвіткою шляху,
  телеграфний ключ (тап — крапка, утримання — тире) з автоматичним розділенням літер і слів за таймінгом.
- **Текст** — кодування тексту в Морзе з відтворенням звуком (Web Audio) і підсвіткою поточної літери.
- **Диктант** — караоке по морзянці: вводиш слово або речення, застосунок веде по ньому літера за літерою,
  показує код і наспів (ді-даа), підсвічує крапки й тире в міру того, як ти стукаєш їх на ключі,
  і наприкінці показує час, помилки та точність.
- **Метод Коха** — слухання на робочій швидкості з першого дня: сеанс починається з двох літер (К і М),
  ти записуєш почуті групи по 5 знаків, і щойно точність сягає 90% — автоматично додається наступна літера
  за класичним порядком Коха (32 літери для української, 26 для англійської).
- **Паузи Фарнсворта** — знак звучить на повній швидкості (за замовчуванням 18 WPM), а паузи між літерами
  розтягнуті до ефективної (10 WPM) за формулою ARRL: `ta = (60c - 37.2s)/(c*s)`, 19 одиниць пауз на слово PARIS.
  Обидві швидкості налаштовуються окремо.
- **Тести** — 12 рівнів від легкого до складного: впізнавання знаків, зворотна задача «літера → код»,
  розпізнавання на слух, відстукування на ключі, слова, цифри, швидкісний раунд 20 WPM.
  Прогрес і зірки зберігаються локально окремо для кожної мови.
- **Таблиця** — усі літери, цифри та розділові знаки, тап по комірці програє звук.

Налаштування: мова (UA/EN), швидкість 6–28 WPM, тон 350–1000 Гц, звук ключа, авто-розділення літер.

## Українська таблиця

Використано кириличну таблицю з «пластівським» варіантом для Ї:
`И = -.--`, `І = ..`, `Ї = .---.`, `Є = ..-..`, `Ґ = --.` (збігається з Г).
В офіційному регламенті Ї кодується так само, як І.

## Запуск

Відкрий `index.html` на будь-якому статичному хостингу (GitHub Pages підійде).
На iPhone: Safari → «Поділитися» → «На екран Домівка» — запуститься на весь екран і працюватиме без інтернету.
